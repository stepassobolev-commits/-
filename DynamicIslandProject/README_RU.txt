DYNAMIC ISLAND — проект для Windows 11
======================================

Что входит в прототип:
- Компактная плавающая капсула сверху по центру экрана.
- Раскрытие при наведении мыши.
- Часы и дата.
- Последние 5 скопированных текстовых фрагментов с временем копирования (только в памяти).
- Повторное копирование записи нажатием.
- Управление воспроизведением через системные медиасессии Windows (Spotify и другие совместимые приложения).
- Отображение названия трека и исполнителя.
- Регулировка общей громкости Windows.

ВАЖНО:
Это исходный проект-прототип, а не уже собранный и проверенный установщик.
Сборка WPF-приложения требует Windows. В этой среде нельзя подтвердить работу
готового .exe на вашем ПК. После сборки обязательно проверьте все функции.

Автоматическая сборка:
В архив добавлен GitHub Actions workflow (.github/workflows/build-installer.yml).
После публикации проекта в GitHub и запуска workflow на Windows runner он соберёт
DynamicIsland-Setup.exe и прикрепит его к запуску как artifact. Это не требует
установки инструментов разработки на пользовательский ПК, но требует загрузить
проект в GitHub и запустить сборку.

Ручная сборка на Windows (если нужна):
1. .NET 10 SDK: https://dotnet.microsoft.com/download/dotnet/10.0
2. Inno Setup 6: https://jrsoftware.org/isdl.php

Как собрать:
1. Распакуйте архив в отдельную папку.
2. Откройте папку проекта.
3. Нажмите правой кнопкой на Scripts\Build-Installer.ps1.
4. Выберите "Выполнить с помощью PowerShell".
   Если политика PowerShell блокирует запуск, откройте PowerShell в папке проекта
   и выполните:
       powershell -ExecutionPolicy Bypass -File .\Scripts\Build-Installer.ps1
5. После успешной сборки установщик появится в папке dist:
       DynamicIsland-Setup.exe

Установка:
Запустите DynamicIsland-Setup.exe и следуйте инструкциям установщика.

Ограничения первой версии:
- История буфера обмена хранится только в оперативной памяти и очищается при закрытии приложения.
- Сохраняется только текст; изображения и файлы не сохраняются.
- Приложение пропускает некоторые явно похожие на пароли/ключи и номера банковских карт строки, но это не гарантированная защита. Не копируйте секреты при включённой истории.
- Медиаданные и кнопки работают через Windows System Media Transport Controls.
  Приложение должно поддерживать системные медиасессии, чтобы отображаться корректно.
- Визуальный эффект пока имитирует стекло прозрачной панелью и тенью; полноценный
  системный Acrylic/Blur можно улучшить в следующей версии.
- Автозапуск пока не включён; его можно добавить после проверки базовой версии.

Если сборка выдаст ошибку:
Скопируйте весь текст ошибки и отправьте его мне. Не меняйте файлы вручную.
